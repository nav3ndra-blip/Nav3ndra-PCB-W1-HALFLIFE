# Nav3ndra PCB – Week 1 (Hack Club Half Life)

This is my Week 1 PCB project for Hack Club’s Half Life program 2026.
It is a custom hexagon-shaped PCB with my nickname “Nav3ndra*, a 'bass guitar logo', and a 'Spiderman spider logo' added as SVG graphics.

## What’s included
- KiCad project file (`.kicad_pro`)
- PCB layout (`.kicad_pcb`)
- Schematic (`.kicad_sch`)
- Custom SVG graphics used on the board
- My 5-hour progress reel video
